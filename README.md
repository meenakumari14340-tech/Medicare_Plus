# MediCare Plus – Smart Hospital Management System

MediCare Plus is a web-based hospital management application designed to provide a modern workspace for managing hospital operations. It features a role-based login interface for administrators, doctors, and receptionists, along with a dashboard for accessing essential hospital management functions.

### Key Features
- **Login System:** Demo login interface with role selection.
- **Dashboard:** Centralized workspace for hospital operations.
- **Patient Management:** Designed to support patient-related information and records.
- **Doctor Management:** Access doctor-related information.
- **Appointment Scheduling:** Support for managing appointments.
- **Pharmacy & Lab Reports:** Sections for pharmacy and laboratory-related operations.
- **Billing Management:** Support for hospital billing workflows.
- **Search:** Search interface for patients, doctors, and related information.
- **Dark Mode:** Theme toggle for improved viewing comfort.
- **Responsive Interface:** Modern hospital dashboard layout.

### Technologies Used
HTML5, CSS3, JavaScript

### Project Type
Frontend Web Development

### Objective
To develop a user-friendly hospital management interface that organizes essential hospital workflows in a centralized digital workspace.
